# Security policy

Security fixes are provided for the newest public integration release. The
integration stores a Puzzary API token in Home Assistant's configuration entry;
never include a real token or production response in a report.

Report vulnerabilities privately at:

https://github.com/barrelcollector/puzzary-home-assistant/security/advisories/new

Include affected versions, reproduction steps and impact. Do not open a public
issue for an unpatched vulnerability.
